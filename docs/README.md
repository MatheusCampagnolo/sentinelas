# Documentation

This folder contains the small set of maintained project documents:

- [System architecture](architecture.md): data flow, components, contracts, and map behavior.
- [AWS backend](aws-backend.md): recorded AWS resources, API contracts, testing, and deployment-status caveats.
- [Device onboarding](device-onboarding.md): add a DynamoDB record and keep its ID consistent across firmware and dashboard.

The dashboard is intended for urban maintenance teams. It is not a resident or driver application. Historical brainstorming and PPI working notes remain in the separate Obsidian vault and are not copied into this GitHub repository.
